# BookCatalogue — Каталог книг

## Опис проєкту

BookCatalogue — навчальний застосунок мовою Java з графічним інтерфейсом JavaFX для керування каталогом книг.

Проєкт розроблено з використанням принципів об'єктно-орієнтованого програмування: інкапсуляції, успадкування та поліморфізму.

## Використані технології

- Java 21
- JavaFX 21
- Apache Maven
- Visual Studio Code
- Java Serialization

## Функціональні можливості

- Додавання нових книг.
- Видалення книг за назвою.
- Оновлення інформації про книги.
- Перегляд усіх книг у таблиці.
- Пошук за повною або частковою назвою.
- Скидання параметрів пошуку.
- Збереження каталогу у файл `.dat`.
- Відновлення каталогу із файлу.
- Перевірка введених даних.
- Обробка помилок із повідомленнями користувачу.

## Структура проєкту

`Publication.java` — базовий клас публікації, який реалізує Serializable.

`Book.java` — клас книги, що наслідує Publication.

`Catalogue.java` — клас керування колекцією публікацій.

`BookNotFoundException.java` — власний клас винятків.

`BookGUI.java` — графічний інтерфейс JavaFX.

## Запуск програми

### Вимоги

- Встановлений JDK 21.
- Apache Maven.
- Доступ до Maven Central для першого завантаження залежностей.

### Команди

Клонувати репозиторій:

```bash
git clone https://github.com/USERNAME/BookCatalogue.git
```

Перейти до папки:

```bash
cd BookCatalogue
```

Скомпілювати:

```bash
mvn clean compile
```

Запустити:

```bash
mvn javafx:run
```

Замініть `USERNAME` на ім'я власного GitHub-акаунта.

## Інструкція користувача

1. Запустіть програму.
2. Заповніть поля назви, автора, видавництва, року та жанру.
3. Натисніть «Додати книгу».
4. Для редагування виберіть книгу в таблиці.
5. Для пошуку введіть назву або її частину.
6. Для збереження використовуйте кнопку «Зберегти у файл».
7. Для відновлення даних натисніть «Завантажити з файлу».
